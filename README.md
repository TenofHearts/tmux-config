# tmux configuration

Press `Ctrl+a`, release it, then press `?` for help. Each mode and picker has its own `?` page. Press `q` to return.

The status badge shows the active mode. After a pane, window, or resize action, press `Esc` or `Enter` to return to typing in the shell.

Drag to copy into the tmux buffer; right-click in a shell pane to paste it. Use your terminal's paste shortcut for the system clipboard.
